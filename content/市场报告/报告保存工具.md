# 报告保存工具

这是 Mike 保存市场报告到 Obsidian 的指导文档。

## 保存步骤

### 1. 创建报告文件
```bash
# 替换 YYYY-MM-DD 为当天日期
DATE=$(date +%Y-%m-%d)
REPORT_FILE="/home/ubuntu/.openclaw/workspace/hzhw-workspace/quartz/content/市场报告/${DATE}.md"
```

### 2. 使用标准模板
报告应包含以下部分：
- 标题和日期
- 分析师信息
- 今日头条（带原文链接）
- 趋势观察
- X热门话题
- 投资建议
- 市场情绪评估
- 数据来源声明

### 3. Git 操作
保存后执行：
```bash
cd /home/ubuntu/.openclaw/workspace/hzhw-workspace/quartz
git add "content/市场报告/${DATE}.md"
git commit -m "feat: 添加 ${DATE} 市场分析报告"
git push origin v4
```

### 4. 更新索引
在 `市场报告索引.md` 中添加新报告链接：
```markdown
## 最近报告
- [[${DATE}]] - ${报告标题摘要}
```
